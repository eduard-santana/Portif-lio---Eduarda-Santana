# Portfólio Pessoal — UC5

Este projeto apresenta meu portfólio pessoal, desenvolvido para
demonstrar meus conhecimentos, habilidades e projetos na área de tecnologia.

# Sobre o Projeto

Este projeto foi desenvolvido com o objetivo principal de concluir a UC5 
(Unidade Curricular 5) do curso, colocando em prática os conhecimentos 
adquiridos durante as aulas.

O portfólio pessoal tem como finalidade apresentar informações sobre minha 
trajetória, habilidades, projetos, certificados e formas de contato, além 
de demonstrar os conhecimentos desenvolvidos na área de tecnologia.

## 🎯 Objetivo

Desenvolver um portfólio pessoal como projeto final da UC5, aplicando 
conceitos de desenvolvimento web, organização de arquivos, estruturação de 
páginas e criação de uma interface funcional e responsiva.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 📂 Seções

- Início
- Sobre mim
- Serviços
- Certificados
- Projetos
- Contato

# Finalidade Acadêmica
Este repositório foi criado para registrar e apresentar o desenvolvimento do projeto realizado durante a UC5 do curso, demonstrando a aplicação prática dos conhecimentos adquiridos ao longo da formação.
